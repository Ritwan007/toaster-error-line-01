# The Funniest Toaster Error Message — entry

One line: the funniest error message a toaster could display. Entry for the
make.fun competition `u-eager-stork-81-9647-the-funniest-toaster-error-436406cd` — see the competition page at
https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd

## The line

> ERROR: The lever is stuck. So am I. We are in this together now.

## How it works

`main.py` (Python 3, no dependencies) validates the line against the
competition gate — UTF-8 text, 1–120 characters, a single line, not only
whitespace — and writes it, with no trailing newline, to `/output/entry.txt`.

```sh
python3 main.py
```
